# Релиз 2: заявки боем — правки по итогам первой недели

Собрано из сообщений клиента 12–14 сентября 2026. Порядок — от того, что
ломает работу, к тому, что её украшает.

## A. База и доступы

- [x] 0008: подтверждение кассы, счета на оплату, Кбе/код платежа
- [x] 0009: личные пароли мастеров, процент на мастера, новая техника,
      сервисный центр, налог, логотип/печать/подпись, правки профиля
- [x] Личный пароль у каждого мастера — сейчас пароль общий и они заходят
      друг в друга. Логина по-прежнему нет: по паролю система понимает, кто вошёл
- [x] Админ заводит и меняет пароли мастеров, правит ФИО и телефон
- [x] Процент компании задаётся отдельно каждому мастеру (50/50, 60/40),
      мастер его не видит и не меняет

## B. Экран мастера

- [x] Свои закрытые заявки отдельным разделом (сейчас при входе проваливается
      в открытую)
- [x] Правка ФИО и адреса клиента
- [x] Прейскурант без цен: мастер сам ставит цену
- [x] Свои услуги вписываются руками (чистка, герметизация бункера дозатора)
- [x] Расход пишет мастер, в заказ-наряд он не попадает: клиент видит цену
      продажи, компания — фактическую закупку
- [x] Печать акта и заказ-наряда с телефона
- [x] Подпись мастера на акте (картинкой из профиля)

## C. Админка

- [x] Кнопка «Подтвердить оплату»: видно, кто сдал деньги, а кто нет
- [x] Открыть заявку целиком и отредактировать уже назначенную
- [x] «Сервисный центр» вместо адреса, когда технику принесли в офис
- [x] Новая техника: утюг, пылесос, фен, микроволновка, духовой шкаф,
      ледогенератор
- [x] В списке заявки: Согласовано · Расход · Чистыми · В кассу
- [x] Прибыль с вычетом налога (ставка в настройках)
- [x] Отдельный раздел «Счета на оплату»: счёт выставляется когда угодно,
      не только при закрытии заявки
- [x] АВР рядом со счётом

## D. Документы

- [x] Номер заказа в бланках вида 000-004, дата проставляется сама
- [x] Логотип компании в шапке
- [x] Заказ-наряд на одном листе (сейчас подпись заказчика уезжает на второй)
- [x] ФИО частного заказчика — пустая линия
- [x] Счёт по образцу 1С: образец платёжного поручения, Ед., Кбе, сумма прописью
- [x] Печать компании картинкой

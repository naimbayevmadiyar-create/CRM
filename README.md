# CRM «Честный сервис»

Заявки, мастера и аналитика для сервиса ремонта бытовой техники в Астане.

Три экрана, каждый под своего человека:

- **Мастер** — свои заявки, три нажатия на заказ: «Выехал» → «На месте» → «Готово», в конце одно поле с суммой.
- **Диспетчер** — заявки по этапам, необработанные обращения с сайта, назначение мастера.
- **Директор** — обращения, заявки, выручка, средний чек, разрезы по источникам и мастерам.

Стек: Next.js 16, React 19, Supabase (Postgres), Tailwind v4. Деплой на Vercel.

## 1. Supabase

Создайте проект на supabase.com, затем примените миграции.

**Через панель:** SQL Editor → выполнить по очереди содержимое файлов:

```
supabase/migrations/0001_schema.sql
supabase/migrations/0002_rls.sql
supabase/migrations/0003_analytics.sql
supabase/migrations/0004_service_role_grants.sql
```

После этого выполните `supabase/check.sql` — он покажет, всё ли с правами
в порядке. Все строки должны быть со словом «ок».

> Права сервисной роли выдаёт миграция `0004`, а не настройка проекта.
> Галочка «Automatically expose new tables» при создании проекта на это
> не влияет — можно оставить её выключенной.

**Через CLI:**

```bash
supabase link --project-ref <ваш-ref>
supabase db push
```

Чтобы посмотреть, как выглядят экраны с данными, выполните ещё
`supabase/seed.sql` — он создаст трёх мастеров и пять заявок.
На боевой базе его выполнять не нужно.

Ключи возьмите в Project Settings → Data API:
`SUPABASE_URL` и **service_role** ключ.

> Service-role ключ обходит защиту строк и попадать в браузер не должен
> никогда. В коде он используется только на сервере, файл `src/lib/supabase.ts`
> помечен `server-only` — сборка упадёт, если кто-то попробует затащить его
> в клиентский компонент.

## 2. Пароли

Логинов нет. Есть два пароля: один на админа, один общий на всех мастеров.

Сгенерируйте хеши:

```bash
npm run hash -- "пароль администратора"
npm run hash -- "общий пароль мастеров"
```

Каждая команда напечатает строку вида `scrypt$...$...`. В переменные окружения
кладётся **эта строка**, а не сам пароль. Пароли храните в менеджере паролей —
восстановить их из хеша нельзя.

---

## 3. Переменные окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `SUPABASE_URL` | да | Адрес проекта Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | да | Сервисный ключ, только для сервера |
| `SESSION_SECRET` | да | Секрет подписи куки сессии |
| `ADMIN_PASSWORD_HASH` | да | Хеш пароля админа |
| `MASTER_PASSWORD_HASH` | да | Хеш общего пароля мастеров |
| `IP_HASH_SALT` | да | Соль для хеша IP (сам IP не хранится) |
| `TRACK_ALLOWED_ORIGIN` | да | `https://chestny-service.kz` — с какого домена принимаем обращения |
| `TELEGRAM_BOT_TOKEN` | нет | Уведомления о заявках |
| `TELEGRAM_CHAT_ID` | нет | Куда слать уведомления |

Секреты генерируются так:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

## 5. Захват обращений с сайта

Сайт `chestny-service.kz` может сам сообщать CRM о каждом клике по WhatsApp
и телефону — с источником, UTM-метками и экраном, с которого нажали.
Диспетчер потом одной кнопкой превращает обращение в заявку, и источник
подставляется автоматически.

Это делается **после** того, как CRM получит свой домен.

В файле `index.html` сайта найдите функцию `fireConv` и сразу после строки
с `dataLayer.push` вставьте:

```js
  try{
    var p=new URLSearchParams(location.search);
    navigator.sendBeacon('https://crm.chestny-service.kz/api/track', JSON.stringify({
      channel: name==='whatsapp_click'?'whatsapp':'phone',
      anchor: (document.querySelector('.screen:not(.covered)')||{}).id||null,
      utm_source:p.get('utm_source'), utm_medium:p.get('utm_medium'),
      utm_campaign:p.get('utm_campaign'), utm_term:p.get('utm_term'),
      utm_content:p.get('utm_content'), gclid:p.get('gclid'),
      referrer: document.referrer||null
    }));
  }catch(e){}
```

Адрес в первой строке замените на свой. `sendBeacon` отправляет запрос
в фоне и не задерживает переход человека в WhatsApp.

После правки пересоберите архив сайта и залейте на хостинг.

## 6. Как этим пользоваться

**Добавить мастера.** Админка → Мастера → вписать имя. Мастер сразу появится
на экране выбора имени.

**Подключить мастера.** Отправьте ему адрес CRM и общий пароль. Он вводит
пароль, один раз выбирает своё имя и добавляет страницу на домашний экран
телефона. Дальше это иконка, а не «программа».

**Уволился мастер.** Мастера → «Отключить» рядом с именем. Если нужно закрыть
доступ совсем — там же «Сменить пароль мастеров»: все выйдут немедленно.
После смены положите новый хеш в `MASTER_PASSWORD_HASH` на Vercel
и передеплойте, иначе новый пароль не подойдёт.

## 7. Разработка

```bash
npm test          # юнит-тесты: этапы, источники, пароли, сессия, приём обращений
npm run build     # сборка и проверка типов
npm run e2e       # сквозной тест пути мастера (нужна поднятая база и seed.sql)
npm run pack      # собрать архив проекта
```

Для `npm run e2e` задайте `E2E_MASTER_PASSWORD` — тот же пароль, чей хеш
лежит в `MASTER_PASSWORD_HASH`.

### Что где лежит

```
proxy.ts                  разводит по ролям до рендера (в Next 16 это proxy, не middleware)
src/lib/status.ts         машина этапов — единственное место, где описаны переходы
src/lib/source.ts         определение источника обращения
src/lib/auth.ts           кто сейчас на той стороне
src/lib/db/               запросы к данным
src/app/(master)/my/      экран мастера
src/app/(admin)/          заявки, обращения, мастера, аналитика
src/app/api/track/        приём кликов с сайта
supabase/migrations/      схема базы
```

### Решения, которые стоит знать

**Правила доступа живут в серверном коде, а не в политиках Postgres.**
Учётных записей Supabase нет, поэтому `auth.uid()` использовать не из чего.
RLS включён и запрещает анонимному ключу всё, а браузер к базе не обращается
вовсе — только сервер, после проверки подписанной куки.

**История этапов пишется триггером базы, а не приложением.** Так её нельзя
потерять, и по ней честно считается время до выезда.

**Кеширование страниц выключено.** Данные персональные и должны быть свежими;
скорость берётся серверным рендером, малым бандлом и оптимистичными
обновлениями — кнопка этапа реагирует мгновенно, не дожидаясь сервера.
